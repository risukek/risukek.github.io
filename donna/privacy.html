Privacy policy: Donna Gmail Readonly

Last updated 2026-11-01.

What is accessed

Donna requests only the Gmail read-only scope (https://www.googleapis.com/auth/gmail.readonly). It cannot send, delete or change email.

How it is used

Email content is used only to show the account owner their own follow-ups and suggested tasks. Donna runs on the owner's own computer; the OAuth token and derived data are stored there and are not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Donna's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
